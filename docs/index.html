About agentmode

A lightweight Rust CLI that prevents macOS from sleeping when you close the laptop lid. Built specifically for modern AI agent workflows (Claude Code, LLM agents, long-running script executions).

Unlike standard caffeinate, agentmode is fully process-aware: it holds the macOS sleep assertion exactly as long as your agent runs, then cleanly releases it automatically. It can also send Telegram notifications when the task finishes.

Key Features

🔒 Lid-close Sleep Prevention

Uses IOKit PreventUserIdleSystemSleep assertion directly. Keeps Mac awake even with closed lid.

🎯 Process-Aware

Launches a command and monitors it. Releases power assertions immediately when your command exits.

👁 Attach to PID

Attach sleep assertions directly to an already-running process by specifying its Process ID (PID).

📬 Telegram Notifications

Get status updates directly to your Telegram bot on task start, completion, and exit status.

Installation

Choose one of the simple methods below to install agentmode:

Option 1: One-line install (Recommended)

Runs the official installation script which detects your platform and architecture, and installs the binary to ~/.local/bin/agentmode:

curl -fsSL https://raw.githubusercontent.com/Mitriyweb/agentmode/main/install.sh | bash

Option 2: From source

Clone and build from source code (requires Rust 1.75+):

git clone https://github.com/Mitriyweb/agentmode.git
cd agentmode
cargo build --release
cp target/release/agentmode /usr/local/bin/

Usage Examples

Run an AI agent or any shell script:

agentmode run "claude -p 'analyze this codebase' --output-format json"

Attach to an already running task:

# Attach to PID 12345
agentmode attach 12345

Keep awake indefinitely until Ctrl+C:

agentmode keep "downloading heavy datasets"
