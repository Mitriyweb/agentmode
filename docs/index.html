About agentmode

A lightweight Rust CLI that prevents macOS from sleeping when you close the laptop lid. Built specifically for modern AI agent workflows (Claude Code, LLM agents, long-running script executions).

Unlike standard caffeinate, agentmode is fully process-aware: it holds the macOS sleep assertion exactly as long as your agent runs, then cleanly releases it automatically. It can also send Telegram notifications when the task finishes.

Key Features

🔒 Lid-close Sleep Prevention

Uses IOKit PreventUserIdleSystemSleep assertion directly. Keeps Mac awake even with closed lid.

🎯 Process-Aware

Launches a command and monitors it. Releases power assertions immediately when your command exits.

👁 Attach to PID

Attach sleep assertions directly to an already-running process by specifying its Process ID (PID).

📬 Telegram Notifications

Get rich messages on your phone — hostname, command, PID, exit code, elapsed time — on start and finish. Zero extra dependencies.

Installation

Choose one of the simple methods below to install agentmode:

Option 1: One-line install (Recommended)

Runs the official installation script which detects your platform and architecture, and installs the binary to ~/.local/bin/agentmode:

curl -fsSL https://raw.githubusercontent.com/Mitriyweb/agentmode/main/install.sh | bash

Option 2: From source

Clone and build from source code (requires Rust 1.75+):

git clone https://github.com/Mitriyweb/agentmode.git
cd agentmode
cargo build --release
cp target/release/agentmode /usr/local/bin/

Usage Examples

Run an AI agent or any shell script:

agentmode run "claude -p 'analyze this codebase' --output-format json"
agentmode run "bun swarm/index.ts"
agentmode run "python train.py --epochs 100"

Full shell syntax (pipes, &&, etc.):

agentmode run "cd ~/project && npm run build && npm test"

Attach to an already running task:

# Find your agent's PID
ps aux | grep swarm

# Attach agentmode to it
agentmode attach 12345

Keep awake indefinitely until Ctrl+C:

agentmode keep "downloading heavy datasets"

📬 Telegram Notifications

Get notified on your phone the moment an agent starts or finishes — with hostname, command, exit code, and elapsed time.

  1. Create a bot — open Telegram, message @BotFather, send /newbot, and copy the token it gives you.
  2. Get your chat ID — message @userinfobot and copy the numeric ID it replies with.
  3. Export the variables — add to your shell profile (~/.zshrc or ~/.bashrc): 
    export TELEGRAM_TOKEN="123456:ABC-your-token"
export TELEGRAM_CHAT_ID="987654321"
    Then run any agentmode command as normal — notifications are automatic.

Sample messages

On success
✅ agentmode done — Success 🖥 Host: my-macbook.local 💻 Command: bun agent-team/index.ts 🔢 Exit code: 0 ⏱ Elapsed: 14m 32s
On failure
❌ agentmode done — Failed 🖥 Host: my-macbook.local 💻 Command: bun agent-team/index.ts 🔢 Exit code: 1 ⏱ Elapsed: 2m 5s

How it works

⚡Acquire IOKit PreventUserIdleSystemSleep assertion — Mac stays awake
🚀Spawn child process (your command)
📬POST to api.telegram.org/sendMessage → Start notification with PID & hostname
⏳Poll child process every 500 ms, waiting for exit
📬POST to api.telegram.org/sendMessage → Done notification with exit code & elapsed time
🔓Drop IOKit assertion — Mac can sleep again (even on crash, via Rust Drop)

Telegram errors are printed as warnings and never abort your command. Messages use HTML parse mode for rich formatting.
